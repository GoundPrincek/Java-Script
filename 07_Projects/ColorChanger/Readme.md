# Color Changer

A simple JavaScript project that changes the webpage background color when the user clicks a button.

This project is created to practice basic **DOM manipulation and JavaScript events**.

## Features

* Change background color on button click
* Basic DOM element selection
* Click event handling
* Dynamic CSS manipulation

## Technologies

* HTML5
* CSS3
* JavaScript

## JavaScript Concepts

* `document.getElementById()`
* `addEventListener()`
* Click events
* Functions
* DOM manipulation
* `style` property
* `console.log()`

## Project Structure

```text
01-color-changer/
│
├── index.html

├── script.js
└── README.md
```

## How It Works

```text
User clicks button
       ↓
JavaScript detects click
       ↓
Function executes
       ↓
Background color changes
```

## Purpose

The main purpose of this project is to understand how JavaScript interacts with HTML elements and responds to user actions.

This is the first project in my JavaScript learning journey and will be used to strengthen my practical understanding of JavaScript.
